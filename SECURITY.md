# Reportar una vulnerabilidad

No publiques vulnerabilidades, tokens, contraseñas, archivos de perfil ni pasos que expongan cuentas reales en una issue pública.

Cuando el repositorio esté publicado, usá **Security → Report a vulnerability** para enviar un reporte privado. Si esa opción no está habilitada, contactá en privado a las personas mantenedoras mediante el canal indicado en el perfil del proyecto.

Incluí la versión afectada, el impacto, los pasos mínimos para reproducir el problema y una posible mitigación. Eliminá nombres de usuario, rutas personales, cookies, archivos `auth.json` y cualquier otra credencial del material del reporte.

Account Hub ejecuta procesos con los permisos de la cuenta de Windows que lo inició. La terminal integrada no es un sandbox. El modo web es local y debe permanecer ligado a `127.0.0.1`; no lo expongas a una red.
